# NaijaHub — Local Business Discovery Platform

NaijaHub is a web application designed to help people discover local businesses, explore services, find deals, and contact businesses across Nigeria.

## Project Overview

The platform provides business listings, individual business profiles, customer reviews, and an administration dashboard for managing submitted listings.

## Features

- **Business discovery:** Browse local businesses by category and location.
- **Business profiles:** View business descriptions, contact details, and ratings.
- **Business submissions:** Allow businesses to submit listings for review.
- **Admin dashboard:** Manage business listings and approve or reject submissions.
- **Reviews and ratings:** Submit customer reviews, moderate them, and display approved feedback.
- **Featured listings:** Manage featured business placement.
- **Payment integration:** Paystack Test Mode checkout is being developed for featured listings; live payment processing is not yet enabled.

## Technologies Used

- PHP
- MySQL / MariaDB
- HTML5
- CSS3
- JavaScript
- XAMPP for local development
- Paystack API in Test Mode
